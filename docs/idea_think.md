# 需求描述
我母语是中文，英语停留在书面语言熟练程度上，但是口语很差。上班的时候，不方便听音频，但我会英语音标，可以一边对照音标一边默读练习。为了提升英语口语水平，我准备做一个Chrome插件，在Chrome商店搜了几个，比如音标助读，比如IPA Reader等等等，都不是我想要的。

# 我的思路
参照沉浸式翻译插件，你可以看到immersivetranslate.png, detail_1.png, detail_2.jpg, detail_3.jpg，这个插件能够实现一键翻译英语文本，双语对照。我想做一个同样的，区别是点击翻译的时候，对照的不是翻译译文，而是英语的音标。

为了节省时间和精力，我去搜索有没有沉浸式翻译插件的开源，发现了一个网站提供代码开源，官网：https://www.readfrog.app，开源地址：https://github.com/mengxi-ream/read-frog

我觉得我可以直接用这个项目开发，原有功能不动，在translate后面加一个phonetic的按钮，表示只用来给网页做原文和音标对照，在按钮的下面新增一个复选框，勾选的话，就是原文+译文对照+音标对照。
用户使用的时候可以根据自己的需要，是要译文，还是要音标练习口语。
